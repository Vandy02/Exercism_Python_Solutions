## 🐍 Exercism Python Solutions
Welcome to my collection of Python solutions! This repository tracks my progress as I work through the Python Track on Exercism.

## 📖 About
Exercism is a platform that helps you level up your coding skills through practice and constructive feedback. This repo serves as my personal archive for the exercises I have completed, focusing on clean, idiomatic Python code and algorithm optimization.

## 📂 Repository Structure
The solutions are organized by exercise name. Each folder contains:

exercise_name.py: The solution implementation.

exercise_name_test.py: The corresponding test suite provided by Exercism to verify the solution.

## 🛠️ How to Run
To run the tests for a specific exercise, navigate to the exercise directory in your terminal and use:

```bash
pytest exercise_name_test.py
```
